# Anexo II — primer párrafo recomendado

**VLC PROACTIVA (València Proactiva / V-PRO)** no es un mapa: transforma el Portal de Datos Abiertos del Ayuntamiento de València en una capa de decisión pública. Detecta ocupaciones de vía pública, tráfico, ZBE y eventos con impacto, calcula zonas afectadas con PostGIS, muestra ubicaciones comprensibles para la ciudadanía y recomienda acciones útiles según el perfil de la persona usuaria. La innovación principal es que **V-PRO no solo consume datos abiertos, produce nuevos datos abiertos derivados de la experiencia ciudadana real**: zonas de impacto, acciones recomendadas y feedback agregado anónimo se publican bajo CC-BY 4.0 para cerrar una economía circular del dato: `evento -> impacto -> acción -> evaluación ciudadana -> mejora pública`.
