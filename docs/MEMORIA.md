# Memoria tecnica publica

Valencia Proactiva convierte datos abiertos municipales en informacion operativa y auditable:
fuente oficial, evento interpretable, impacto orientativo, alternativa cercana y evidencia reutilizable.

## Problema publico

Los datos abiertos municipales existen, pero a menudo llegan como registros tecnicos o geometria
aislada. Para una persona usuaria la pregunta practica es otra: que ocurre, donde ocurre, a quien
afecta, que alternativa cercana existe y de donde sale el dato.

## Solucion

La aplicacion normaliza fuentes oficiales, publica eventos recientes, estima una zona orientativa de
impacto y propone alternativas por perfil. La interfaz separa claramente fuente oficial, calculo
derivado y evidencia exportable.

## Artefactos publicos

- Aplicacion web operativa.
- API y backend reproducible.
- Exports publicos: eventos recientes, zonas de impacto, acciones recomendadas y salud del dato.
- Documentacion de fuentes, metodologia y esquema de datos.
- Pruebas automaticas para ingesta, API, modelos y exports.

## Reproducibilidad

El repositorio publico contiene codigo, configuracion sin secretos, pruebas, esquema de base de datos,
documentacion tecnica y exports derivados. No incluye documentos administrativos, firmas, identificadores
personales, secretos ni notas internas de trabajo.
